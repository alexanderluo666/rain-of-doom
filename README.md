# Rain-of-doom
This is just a simple 2D project created to assist my 3D game development, this is built using the raylib library installed, and using C++.
To run this program, raylib is needed, please visit https://github.com/raysan5/raylib; download all required tools/libraries, then use an installer(apt, dnf, pacman, xbps...) to install package via "(sudo) _installer_ -S/install raylib".
